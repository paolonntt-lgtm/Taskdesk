---
name: Daily report archive scope
description: Product rule for report submission frequency and Albert's historical report search.
---

Operators may publish multiple daily reports in the same day. Reports are separate records, and Albert can search reports from any date within the current organization.

**Why:** A single daily report is not always enough to capture an operator's work, and Albert should answer historical questions from the full organization archive.

**How to apply:** Do not replace or suppress another report based only on author and date. Keep all report lookups scoped to the authenticated organization and avoid arbitrary age cutoffs.
