---
name: Profile screen information and menu layout
description: User-approved information hierarchy, visual treatment, and navigation behavior for the mobile Profile menu.
---

Keep the email directly below the user's name and role. Do not show separate Account information or App cards. Place the language selector under a Settings heading. Present “Altri strumenti” and “Amministrazione” in one continuous card with distinct section headings and row dividers. Avoid both grids and separately tinted row tiles, but do not make the menu austere: use visible color in icon backgrounds and give the headings enough contrast and character.

When a user opens a Profile section, show a back arrow that returns to Profile and keep the page title in only one place. Retain any subtitle or actions that are useful below the title.

**Why:** The user chose a single-list structure, said the very minimal treatment felt too sparse, and requested clear return navigation without duplicate titles.

**How to apply:** Preserve the email placement, Settings grouping, unified vertical list, menu order, access rules, color accents, and single title/back-button behavior when changing this screen or its destinations.
