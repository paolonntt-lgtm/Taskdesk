name: Profile screen information and menu layout
description: User-approved information hierarchy and balanced visual treatment for the mobile Profile menu.
---

Keep the email directly below the user's name and role. Do not show separate Account information or App cards. Place the language selector under a Settings heading. Present “Altri strumenti” and “Amministrazione” in one continuous card with distinct section headings and row dividers. Avoid both grids and separately tinted row tiles, but do not make the menu austere: use visible color in icon backgrounds and give the headings enough contrast and character.

**Why:** The user chose a single-list structure but explicitly said the very minimal treatment felt too sparse.

**How to apply:** Preserve the email placement, Settings grouping, unified vertical list, menu order, access rules, and add restrained color and stronger section identity without splitting rows into individual cards.
