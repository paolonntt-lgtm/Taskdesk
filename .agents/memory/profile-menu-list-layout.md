name: Profile screen information and menu layout
description: User-approved information hierarchy and continuous-list structure for the mobile Profile screen.
---

Keep the email directly below the user's name and role. Do not show separate Account information or App cards. Place the language selector under a Settings heading. Present “Altri strumenti” and “Amministrazione” in one continuous card with simple section headings and row dividers. Do not use a grid or individually tinted row tiles.

**Why:** The user explicitly chose a single list structure after rejecting earlier Profile menu treatments.

**How to apply:** Preserve the email placement, Settings grouping, omitted cards, unified vertical list, menu order, and access rules when changing this screen.
