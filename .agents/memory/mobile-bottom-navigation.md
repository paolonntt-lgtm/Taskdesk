---
name: Mobile bottom navigation
description: The preferred mobile bottom-bar behavior when optional organization modules are enabled.
---

Use a compact, horizontally scrollable bottom bar for all available mobile sections. Keep the core tabs; show Clients only when the organization has the Clients module, and show the Hours report only to organization admins when TaskTrack is enabled. Keep the daily Report separate from the hours report.

**Why:** The user explicitly chose direct access to all seven tabs, with smaller tab items, rather than replacing core tabs or hiding optional modules behind another menu.

**How to apply:** Preserve module and role gating, keep labels legible in Italian and English, and let users scroll horizontally on narrow screens.
