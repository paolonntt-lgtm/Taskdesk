---
name: Mobile bottom navigation
description: The preferred mobile bottom-bar behavior when optional organization modules are enabled.
---

Use a single bottom row for Dashboard, Tickets, Calendar, and Clients when enabled. Keep New (+) permanently centered as a larger white plus inside a blue circle that protrudes above the bar. Calendar stays visible with every module combination; Hours report stays out of the bottom bar and is available from Profile only to organization admins when TaskTrack is enabled. Do not duplicate the New action beside the Dashboard greeting. Keep Profile and Notifications as top-right header actions; show an unread-count badge on the bell only when the count is above zero. Keep daily Report separate from Hours report.

**Why:** The user wants Calendar and Clients to remain available in one row when both optional modules are active, without giving up the prominent centered New action.

**How to apply:** Preserve module and role gating, keep labels legible and tappable on compact screens, and keep Notifications and Profile available from the header.
