---
name: Profession mark presentation
description: Visual consistency rules for profession logos and icons in the TaskDesk landing.
---

Render all profession marks in the same white, fixed-size tile in both the profession chooser and landing cards. Center each mark, title, and supporting description. Preserve each logo's aspect ratio; do not use different tile backgrounds for individual professions.

**Why:** The user explicitly requested the same background and size for all profession marks after noticing different logo backgrounds.

**How to apply:** Keep shared mark styling in the reusable profession-mark component and center card content in both the popup and landing section without shifting the title for its arrow indicator.
