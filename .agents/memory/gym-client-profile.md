For gym organizations, keep TaskTrack disabled by default. The client profile uses separate first and last names, tax code, date of birth, address, mobile phone, email, and an optional membership number. Default ticket categories are “Accessi e iscrizioni”, “Abbonamenti e pagamenti”, “Corsi e prenotazioni”, “Attrezzature e struttura”, and “Altro”. Update old gym category defaults only when they still match the standard preset; preserve manually customized categories and existing client data.

**Why:** These are the gym-specific choices explicitly confirmed by the user and should not be replaced with guessed fields or categories.

**How to apply:** Keep gym-specific client forms and category defaults scoped to the gym profession; leave other profession profiles unchanged.
